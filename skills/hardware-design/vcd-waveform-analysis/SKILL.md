# VCD Waveform Analysis Skill

Parses Value Change Dump (VCD) waveform files generated during RTL simulations. Extracts signal value transitions, clock cycles, and bus states around assertion failure timestamps to support visual and programmatic debugging.

## When to Use

- Inspecting signal timelines when an assertion fails at a specific simulation timestamp
- Tracing clock, reset, opcode, and data bus transitions during failed transactions
- Correlating testbench stimuli with DUT output response
- Don't use for: text-only compile errors that did not generate a waveform

## Prerequisites

- `vcdvcd` Python package installed
- VCD waveform file (`.vcd`) generated by Verilator, Icarus, or cocotb

## How to Run

Inspect waveform signal transitions via `terminal`:

```bash
terminal(command="chipship vcd test_corpus/cocotb_alu/dump.vcd", timeout=60)
```

Programmatic extraction in Python:

```python
from eda_agent.vcd_parser import inspect_vcd_waveform
waveform_data = inspect_vcd_waveform("dump.vcd", signals=["clk", "rst_n", "op", "result"])
```

## Quick Reference

| Action | Command Pattern |
|---|---|
| Inspect Waveform Signals | `chipship vcd <path_to_vcd>` |
| Filter Specific Signals | `chipship vcd <vcd> --signals clk rst_n op result` |
| Limit Time Window | `chipship vcd <vcd> --window 1000 5000` |

## Procedure

1. **Verify VCD Existence:**
   Confirm the target `.vcd` file exists using `search_files`.

2. **Inspect Waveform Transitions:**
   Execute `terminal(command="chipship vcd <path_to_vcd>")`. Review total signal count, time range, and inspected signal list.

3. **Trace Signal Values Around Bug:**
   Examine timestamps where signal values transition. Verify whether control signals (e.g. `rst_n`, enable flags, opcode) or data buses contained invalid values at clock edges.

4. **Correlate with Source Code:**
   Map the observed waveform discrepancy to the module's always blocks or state machine transitions.

## Pitfalls

- **Large VCD Files:** Full-chip waveforms can exceed hundreds of megabytes; filter by specific signal names and limit `max_changes`.
- **Clock Edge Timing:** Check whether signals are sampled on positive edge (`posedge clk`) or negative edge.

## Verification

1. Run `terminal(command="chipship vcd test_corpus/cocotb_alu/dump.vcd")`.
2. Confirm output displays `Signal Transition Timeline` with timestamped signal values.
